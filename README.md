# Oh Yes Events Website

A responsive static website for **Oh Yes Events**, showcasing event planning services and enabling potential clients to connect with the company.

## Project Structure

```text
.
├── index.html      # Main webpage
├── style.css       # Website styling
├── script.js       # JavaScript functionality
└── logo.png        # Company logo
```

## Features

* Responsive design
* Modern user interface
* Event services showcase
* Contact and inquiry section
* Fast-loading static website
* Cross-browser compatibility

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Getting Started

### Run Locally

1. Download or clone the project.
2. Open `index.html` in your web browser.

Alternatively, use a local server:

```bash
# VS Code Live Server
Right-click index.html → Open with Live Server
```

## File Description

### index.html

Contains the website structure and content.

### style.css

Handles the visual design, layout, responsiveness, typography, and animations.

### script.js

Manages website interactions and dynamic functionality.

### logo.png

Official logo used throughout the website.
